# Plan 01-01: Scaffold + domain + journal

## Goal

`cargo build` green; domain types enforce balanced i64 minor-unit postings; journal appends full records and acks only after durable sync.

## Threat model

- Amount tampering: i64 + Currency enum, serde denies unknown variants; balance check server-side, never trust client totals.
- Record forgery on disk: crc32c checksum per record; recovery rejects bad checksum (fail-closed, never partial read).
- Blocking: not security-relevant here. PAN: no card fields exist in this schema by construction.
