# Plan 01-02: API + acceptance path

## Goal

POST /payments validates, journal-syncs, returns `{tx_id, status}` with 201; invalid → 422 REJECTED, nothing settled.

## Threat model

- Injection: validator crate constrains account strings (charset/length); serde deny_unknown_fields.
- DoS: tower-http request-body limit + concurrency limit; bounded mpsc(1024) to writer; overload → 503, never unbounded queue.
- Auth: Phase 5 adds authN; this plan binds localhost only and notes the gap in code comment.
