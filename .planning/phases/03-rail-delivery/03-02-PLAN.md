# Plan 03-02: Graceful shutdown + supervision + validated config

## Goal

SIGTERM drains cleanly, crashed partitions restart themselves from WAL, and boot config is validated with a partition-count guard.

## Threat model

- Dirty shutdown lie: shutdown deadline (default 15s) must exceed one group-commit sync; after deadline, exit non-zero so orchestrators know delivery may be incomplete — never exit 0 with unsynced batches.
- Panic loop: supervisor backs off restarts (1s,2s,4s…60s cap); 5 rapid crashes → partition stays down + DLQ `partition-down`, server keeps serving other partitions.
- Config smuggling: unknown env keys rejected at boot (typo'd `PARTITONS` must fail, not silently default).
