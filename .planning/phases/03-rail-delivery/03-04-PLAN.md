# Plan 03-04: TLS + API keys (bank and client)

## Goal

No more localhost-only comment: TLS on all listeners, keyed bank and client planes, identical 401s.

## Threat model (blocks on HIGH)

- Plaintext money movement: TLS required unless explicitly disabled via `TLS_OFF=true` (sandbox only; boot logs WARNING). Cert/key from `TLS_CERT`/`TLS_KEY` paths.
- Key guessing: SHA-256 hash compare (constant-time), keys >= 32 chars enforced at boot, `BANK_KEYS`/`CLIENT_KEYS` as `name:secret` lists.
- Oracle via status codes: missing/invalid/expired key all → identical 401 JSON, same timing path (hash a dummy on miss).
- WS bypass: bank WS requires bank key + bank_id must match the key's owner (a key for bank `user` cannot listen as `merchant`).
