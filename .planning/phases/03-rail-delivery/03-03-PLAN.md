# Plan 03-03: Prometheus exporter + audit log

## Goal

Metrics actually exported and every state change audit-logged. No more blind prod.

## Threat model

- Metric-label cardinality bomb: NEVER put tx_id/key/account in labels — partition, reason, and state only. Test asserts label set is bounded.
- Audit tampering: `audit.wal` append-only with per-record crc (same framing as journal); audit write failure never fails the payment (best-effort + counter `audit_dropped_total`).
- Metrics endpoint exposure: bind PROM_ADDR localhost by default; document that public exposure needs auth (Phase 5 follow-up if this phase keeps it local).
