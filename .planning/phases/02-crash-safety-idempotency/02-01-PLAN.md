# Plan 02-01: Partitioned writers + structured IDs + group commit

## Goal

N parallel journals with hash routing, structured tx IDs, and batched syncs. Same scope+key always routes to the same partition.

## Threat model

- Duplicate escape: router MUST hash idempotency scope+key (+bucket/sender/receiver), never random — a misrouted retry creates a double payment. Test pins this.
- Partition-count change re-routes keys: changing N invalidates idem lookups across restarts — N is read from env at boot and logged; changing N requires drain (document in code comment).
- Queue blowup: per-partition bounded mpsc(1024); overload → 503, never unbounded.
