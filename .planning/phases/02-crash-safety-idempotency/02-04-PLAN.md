# Plan 02-04: Bank websockets + dummy test bank

## Goal

Two live WS planes (`/ws/client`, `/ws/bank`) with acked bank delivery, plus an in-repo `test-bank` binary rehearsing both sides and asserting conservation.

## Threat model

- Unauthenticated WS (Phase 5 adds authN): bind localhost only, comment the gap; bank WS accepts a `bank_id` query param validated against allowlist charset (same allowlist as accounts).
- Ack spoofing: acks accepted only for tx_ids this server issued and still pending; unknown/duplicate acks logged + ignored, never mutate ledger.
- Slow consumer: per-connection bounded mpsc(256); lagging bank gets dropped with `bank-lag-drop` DLQ note, never blocks writers.
