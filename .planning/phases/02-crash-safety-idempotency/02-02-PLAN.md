# Plan 02-02: Per-partition recovery + kill-9 proof

## Goal

Restart rebuilds every partition's indexes from its WAL; all acked txs survive; torn tails discarded. Proven by a kill-9 test, not reasoning.

## Threat model

- Silent loss: replay must fail CLOSED — checksum failure halts that partition's boot with a loud error, never skips a record.
- Torn tail misread as data: wal-db truncates torn tails on open; test writes garbage tail bytes and asserts they vanish.
- Partial partition recovery: if any partition fails replay, server refuses to start (fail-closed, exit non-zero).
